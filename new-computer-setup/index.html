New Computer & Device Setup

New computer? New phone? New tablet? I’ll help with the setup so you can get on with using it.

Your new computer, set up for your life.

Moving to a new device involves more than switching it on. We’ll work through the files, software, accounts, and everyday equipment you rely on, then check the setup together.

  • Windows setup and updates
  • Microsoft account setup
  • File migration from an accessible device or backup
  • Software installation
  • Browser, bookmarks, and email setup
  • Printers and peripheral setup
  • Cloud storage configuration
  • Security and privacy settings

Keep your old device and chargers until the transfer is complete and you’ve checked your important files. You’ll enter your own account passwords when needed. Some paid applications need a license or a new installation from the original provider.

A few common questions

Can you move everything from my old computer?

I can help transfer accessible files and set up supported applications. What can be moved depends on the old device, available backups, software licenses, and account access. We’ll check these before starting.

What if the old computer won’t turn on?

Tell me what it does when you try. File access depends on the fault and the condition of its storage. I’ll discuss the options without promising recovery that hasn’t been assessed.

Can you also connect my printer and monitor?

Yes. Printers, monitors, keyboards, mice, and other everyday peripherals are part of getting the new setup ready to use.
